# Hardcade-Refresh-Rate-Meter-v1.1
A lightweight utility to measure the actual graphics card refresh rate and fine-tune 15 kHz CRT modelines for accurate video timings.

![Hardcade Refresh Rate Meter](https://hardcade-system.com/img/Hardcade-RRM.png)

DESCRIPTION
-----------
Hardcade Refresh Rate Meter is a lightweight utility that measures the actual 
refresh rate generated by the graphics card for the current display mode.

USAGE
-----
This tool is particularly useful for fine-tuning 15 kHz CRT configurations.

Compare the measured refresh rate for the current resolution with the refresh 
rate specified by the modeline applied to that same resolution. This comparison 
helps identify small timing differences and refine video timings for CRT emulation.

VERSIONS INCLUDED
-----------------
(D3D): Uses Direct3D rendering.
(Software): Uses the Standard software-rendering mode.
